# 双基地仓储库存与生产报工管理系统‑软件需求规格说明书

> 项目面向：宁波汽车软轴软管有限公司 运行终端：Web管理后台 + H5移动端（手机浏览器访问） 技术栈
>
> - 后端：SpringBoot
> - Web前端：Vue
> - 数据库：MySQL
> - 移动端：H5 系统角色：**系统管理员、业务管理人员、车间操作工** 文档用途：毕业设计开发文档，作为系统设计、编码、测试依据，可直接复制至Typora

## 1 引言

### 1.1 项目背景

宁波汽车软轴软管有限公司拥有宁波、合肥两大生产基地，主要生产汽车控制拉索总成、操纵机构总成、电子油门踏板总成等汽车零部件。企业内部存在仓储物料批次管理困难、双基地库存缺少统一管理、车间生产报工依靠纸质记录、质量问题难以快速追溯、不良品缺少统计分析、质检报告手工整理等问题。

本系统旨在搭建一套Web+H5的管理系统，实现双基地仓储管理、物料批次追溯、呆滞库存预警、车间H5生产报工、不良品记录、质量统计、质检报告导出等业务能力，覆盖从物料入库、生产加工、报工、质检出库完整业务流程，提升企业仓储与生产环节信息化水平。

### 1.2 项目目标

1. 实现宁波、合肥双基地仓库统一线上管理，支持物料入库、出库、盘点、库存预警。
2. 实现物料批次管理与双向追溯，满足汽车零部件行业质量溯源业务要求。
3. 实现物料呆滞库存识别预警，降低物料积压与资金占用。
4. 车间操作工通过H5移动端完成工单查看、工序报工、不良品录入、完工提交。
5. 支持工单质检审核、不良品分类统计、自动导出质检报告。
6. 实现账号、角色权限控制，关键业务操作日志留痕。

### 1.3 范围

- 包含：Web后台系统、H5移动端报工系统；仓储管理、批次追溯、工单管理、生产报工、质量统计、权限管理。
- 不包含：硬件设备对接、自动化生产采集、财务记账模块、客户销售订单模块。

### 1.4 定义与缩写

| 术语     | 说明                                       |
| -------- | ------------------------------------------ |
| FIFO     | 先进先出，出库优先消耗较早入库的物料批次   |
| BOM      | 物料清单，生产产品所需要原材料、半成品清单 |
| H5移动端 | 手机浏览器访问，无需下载APP、无需小程序    |
| 批次追溯 | 原材料与成品批次互相查询溯源               |

## 2 总体描述

### 2.1 用户角色说明

| 角色         | 角色描述                                                     | 使用终端 |
| ------------ | ------------------------------------------------------------ | -------- |
| 系统管理员   | 负责系统基础维护：账号管理、角色权限分配、基础字典维护、查看操作日志；**不参与仓储、生产实际业务操作** | Web后台  |
| 业务管理人员 | 合并仓库管理、生产管理、质检业务；完成物料出入库、批次管理、呆滞库存查看、生产工单创建分配、工单质检审核、质量统计、质检报告导出等全部业务操作 | Web后台  |
| 车间操作工   | 一线车间员工；通过H5查看个人工单、工序报工、上传照片、录入良品不良品、提交完工申请 | H5移动端 |

### 2.2 运行环境

1. Web后台：Chrome、Edge主流PC浏览器
2. H5移动端：手机微信/手机自带浏览器
3. 服务端：SpringBoot，JDK8
4. 数据库：MySQL8.0

### 2.3 系统约束

1. 所有数据为模拟业务数据，不对接企业真实数据库。
2. H5与Web后台共用同一套后端接口。
3. 权限严格隔离，车间操作工只能看到分配给自己的工单。

## 3 具体需求

### 3.1 功能需求

> 按照角色划分，包含功能描述、输入、输出、业务规则。

#### 3.1.1 系统管理员模块（Web后台）

##### 3.1.1.1 用户账号管理

- 功能描述：新增、编辑、删除、启用/禁用系统用户账号，为用户绑定角色。
- 输入：用户名、密码、真实姓名、选择角色（系统管理员/业务管理人员/车间操作工）。
- 输出：用户列表。
- 业务规则：用户名不可重复；车间操作工账号用于登录H5；禁用账号无法登录系统。

##### 3.1.1.2 角色权限管理

- 功能描述：维护角色，为角色分配菜单访问权限。
- 输入：角色名称，勾选可访问菜单。
- 输出：角色权限配置保存结果。
- 业务规则：系统管理员角色拥有全部菜单权限；业务管理人员拥有全部业务菜单；车间操作工仅拥有H5相关业务权限。

##### 3.1.1.3 基础字典维护

- 功能描述：维护系统公用字典数据，如不良原因字典（原材料缺陷、设备问题、人工操作问题）、生产基地字典。
- 输入：字典名称、字典编码。
- 输出：字典列表。
- 业务规则：业务模块下拉选项从字典读取。

##### 3.1.1.4 系统操作日志查询

- 功能描述：记录并查询关键操作，包含操作人、操作时间、操作模块、操作内容。
- 输入：时间范围、操作人筛选条件。
- 输出：操作日志列表，支持导出。
- 业务规则：入库、出库、工单修改、批次数据变更必须记录日志；日志不允许删除。

#### 3.1.2 业务管理人员模块（Web后台）

##### 3.1.2.1 仓库基础档案管理

- 功能描述：维护宁波、合肥基地仓库档案信息。
- 输入：仓库名称、所属基地、仓库备注。
- 输出：仓库列表。
- 业务规则：仓库绑定对应生产基地，出入库单据必须选择仓库。

##### 3.1.2.2 物料入库管理（含批次录入）

- 功能描述：新增入库单据，入库同时录入物料批次号。
- 输入：选择基地、仓库、物料、入库数量、**物料批次号**、备注。
- 输出：入库单据保存成功，更新物料库存、批次库存。
- 业务规则：入库必须填写批次号；一条入库单可以包含多条物料批次记录；入库单据不可物理删除，只允许作废。

##### 3.1.2.3 物料出库管理（FIFO先进先出）

- 功能描述：新增出库单据，系统自动优先推荐最早入库未消耗完毕的批次。
- 输入：基地、仓库、物料、出库数量、选择出库批次（系统FIFO优先推荐）。
- 输出：出库单据保存成功，扣减对应批次库存。
- 业务规则：出库时优先展示较早入库批次；批次库存不足不允许超量出库。

##### 3.1.2.4 物料批次双向追溯管理

1. **原材料批次正向追溯**
   - 功能描述：输入原材料批次，查询该批次物料被哪些工单领用，产出哪些成品以及对应成品批次。
   - 输入：原材料批次编号。
   - 输出：领用工单列表、工单产出成品与成品批次，支持导出查询结果。
2. **成品批次反向溯源**
   - 功能描述：输入成品批次，反查生产该成品所消耗全部原材料及原材料批次号。
   - 输入：成品批次编号。
   - 输出：耗用原材料清单及对应批次，支持导出。

- 业务规则：批次号必须与入库、生产工单绑定，才可以完成追溯。

##### 3.1.2.5 呆滞库存预警管理

- 功能描述：配置物料呆滞时间阈值，系统自动识别长时间无出入库变动的物料，标记呆滞。
- 输入：呆滞天数阈值配置。
- 输出：呆滞物料列表（物料名称、编码、最后出入库时间、呆滞天数）。
- 业务规则：以物料最后一次出入库时间作为计算起点；超过阈值自动展示在呆滞预警列表。

##### 3.1.2.6 库存监控与盘点管理

- 功能描述：库存查询、库存上下限预警、库存盘点，导出库存台账Excel。
- 输入：盘点实盘数量，筛选条件。
- 输出：库存列表、预警物料列表、库存台账Excel文件。
- 业务规则：低于库存下限的物料进入库存预警列表；盘点后更新系统库存数据。

##### 3.1.2.7 生产工单管理

- 功能描述：创建生产工单，选择基地、产品，绑定BOM信息，填写生产数量，分配给车间操作工。
- 输入：生产基地、产品、BOM、计划生产数量、选择操作工。
- 输出：工单记录，工单状态【待生产】，操作工H5端可见该工单。
- 业务规则：工单分配完成，对应操作工H5才可以看到该任务。工单状态：待生产、生产中、待质检、已完成。

##### 3.1.2.8 生产进度查看

- 功能描述：查看所有工单进度，查看操作工H5上报工序记录、生产照片、良品不良品数据。
- 输入：工单筛选条件（基地、工单状态、操作工）。
- 输出：工单列表、工序报工详情、照片预览、良品不良品统计。

##### 3.1.2.9 工单质检审核

- 功能描述：对操作工提交完工申请的工单执行质检审核，填写审核结果。
- 输入：工单，审核结果（合格/不合格），质检备注，质检环节不良原因。
- 输出：更新工单状态；合格则工单闭环。
- 业务规则：只有状态为待质检工单才可以审核；审核不合格可以退回，操作工可以重新报工。

##### 3.1.2.10 不良品原因分类统计

- 功能描述：聚合H5报工不良、质检环节不良数据，按不良原因分类统计，展示图表。
- 输入：统计时间范围、生产基地筛选。
- 输出：饼图/柱状图，不良统计数据，支持导出Excel。
- 业务规则：统计数据来源于报工和质检填写的不良原因字典。

##### 3.1.2.11 质检报告导出

- 功能描述：工单质检审核合格后，生成简易质检报告文档并下载，用于主机厂交付。
- 输入：选中已合格工单。
- 输出：质检报告文件。
- 业务规则：只有审核状态为合格的工单才允许导出质检报告。

#### 3.1.3 车间操作工模块（H5移动端）

##### 3.1.3.1 H5登录

- 功能描述：操作工输入账号密码登录H5系统。
- 输入：账号、密码。
- 输出：登录成功跳转我的工单页面。
- 业务规则：只有车间操作工角色账号允许登录H5。

##### 3.1.3.2 我的工单列表

- 功能描述：查看分配给自己的全部工单。
- 输入：无，可按工单状态筛选。
- 输出：工单列表，展示工单编号、产品名称、工单状态。
- 业务规则：操作工只能查看分配给自己的工单。

##### 3.1.3.3 工单详情查看

- 功能描述：查看工单零部件信息、工序加工要求。
- 输入：选中工单。
- 输出：工单详情、工序清单。

##### 3.1.3.4 工序报工（含不良品录入、照片上传）

- 功能描述：填报工序加工进度，上传生产现场照片，填写良品、不良品数量，选择不良原因。
- 输入：工序进度、现场图片、良品数量、不良品数量、不良原因。
- 输出：保存工序报工记录。
- 业务规则：不良品数量大于0时必须选择不良原因；图片上传保存至服务端。

##### 3.1.3.5 提交完工申请

- 功能描述：全部工序报工完成后，提交完工申请，工单流转至Web后台待质检。
- 输入：确认提交完工。
- 输出：工单状态更新为待质检。
- 业务规则：必须全部工序完成，才可以提交完工申请；提交后操作工不能随意修改报工记录。

### 3.2 非功能需求

#### 3.2.1 性能需求

1. 普通页面响应时间≤2秒；查询追溯、统计图表页面响应≤3秒。
2. 支持模拟数十用户同时访问。

#### 3.2.2 安全性需求

1. 登录身份认证，未登录用户禁止访问所有业务接口。
2. 权限控制：不同角色只能访问自己权限内功能；车间操作工不能访问仓储、工单创建接口。
3. 密码做简单加密存储。
4. 库存、工单、批次关键操作记录操作日志。

#### 3.2.3 兼容性需求

1. Web后台兼容Chrome、Edge主流PC浏览器。
2. H5移动端兼容主流手机浏览器。

#### 3.2.4 易用性需求

1. Web后台菜单清晰，表单有简单校验提示。
2. H5页面适配手机屏幕，按钮适合手机点击，操作步骤简洁。

## 4 业务流程（用户行为路径摘要）

1. 物料入库：业务管理人员Web后台新增入库单→选择基地仓库→录入物料与批次→提交入库。
2. 物料出库：业务管理人员新增出库单→系统FIFO推荐批次→确认出库扣减库存。
3. 批次追溯：业务管理人员输入批次号，完成原材料正向追溯或者成品反向溯源。
4. 生产流程：业务管理人员Web创建分配工单 →操作工H5看到工单→工序报工、录入不良、上传照片→提交完工申请→业务管理人员Web质检审核→审核合格导出质检报告。
5. 质量分析：业务管理人员选择时间与基地，查看不良品分类统计图表。
6. 系统管理：系统管理员维护账号角色、基础字典、查看操作日志。

## 5 接口简要说明

1. Web后台与H5共用一套后端REST接口。
2. 接口包含：登录接口、用户管理接口、仓库物料库存接口、批次追溯接口、工单接口、报工接口、统计导出接口、文件上传接口。
3. 毕业设计可使用Knife4j生成接口文档。
