# 双基地仓储库存与生产报工管理系统

## 项目简述

本系统面向宁波汽车软轴软管有限公司，针对宁波、合肥双生产基地汽车软轴软管、踏板总成零部件的仓储与车间生产业务。企业管理人员在Web后台完成仓库档案维护、物料出入库单据管理、库存盘点、库存预警、工单创建、质检审核、台账导出；车间操作工通过微信小程序接收生产工单任务，上报各工序加工进度、上传现场生产照片、提交完工申请，企业端Web后台可实时查看库存状态与车间整体生产进度并完成质检审核，实现多厂区从物料入库、生产加工、进度上报到成品出库的全流程线上协同管理。

## 核心功能

### 📟 Web管理后台（企业内部使用：宁波、合肥基地管理人员）

1. 角色权限管理：系统管理员、仓库管理员、质检人员、生产主管，不同角色分配不同菜单与操作权限。
2. 仓库档案管理：仓库信息录入、物料档案维护、仓库状态管理。
3. 库存单据管理：出入库单据创建、物料信息绑定、单据附件上传。
4. 库存监控预警：物料库存查询、库存上下限预警、库存盘点管理、库存台账导出。
5. 生产工单管理：创建车间生产工单，绑定零部件BOM信息，分配工单给对应车间操作工。
6. 生产进度监控：实时查看小程序端车间操作工上报的工序进度、现场生产图片。
7. 质检审核管理：对车间提交的完工工单进行质检结果录入、工单审核。

### 📱 微信小程序端（车间操作工现场使用）

1. 工单任务列表：查看分配给自己的生产工单，查看工单零部件、工序要求。
2. 工序进度填报：按工序节点填写加工进度，记录生产信息。
3. 现场图片上传：上传生产现场照片，作为加工过程凭证。
4. 完工提交申请：工序全部完成后，提交完工申请，等待后台质检审核。

## 技术栈

- 后端：SpringBoot
- Web前端：Vue
- 数据库：MySQL
- 移动端：H5

## 适合理由

汽车零部件制造企业典型业务场景；融合仓储库存管理与车间生产报工两大核心业务，内置多角色权限控制，面向工厂车间B端小程序，区别普通C端小程序，业务流程完整，工作量充足，难度适中。
