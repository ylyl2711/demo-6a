# 双基地仓储库存与生产报工管理系统 用户故事 & 用户行为路径
> 项目背景：面向宁波汽车软轴软管有限公司，宁波、合肥双基地，包含Web管理后台 + H5移动端；
> 系统角色精简为**3个角色**：**系统管理员、业务管理人员、车间操作工**
> - 把原来仓库管理员、生产主管、质检人员合并为「业务管理人员」角色，该角色拥有仓储、工单、质检、质量统计全部业务操作权限，适合毕设简化，又保留全部业务功能。
> 用途：作为需求规格、数据库设计、接口开发的输入依据，可直接复制到Typora用于毕设开发文档。

## 一、角色说明
|角色|角色描述|使用端|
| ---- | ---- | ---- |
|系统管理员|仅负责系统层：账号维护、角色权限分配、查看操作日志、基础字典数据维护；**不参与实际仓储生产业务操作**|Web后台|
|业务管理人员|包含原仓库管理员+生产主管+质检人员全部业务能力；负责物料出入库、批次管理、呆滞库存处理；创建分配生产工单；工单质检审核、不良统计、质检报告导出；查看各类业务数据与图表|Web后台|
|车间操作工|车间一线人员，通过H5移动端查看工单、工序报工、上传照片、录入良品不良品、提交完工申请|H5移动端|

## 二、用户故事（User Story）
> 格式：作为【角色】，我希望【功能】，以便【业务价值】

### 1. 系统管理员 用户故事
1. 作为系统管理员，我希望可以新增、修改、删除系统用户账号，以便管理所有操作人员。
2. 作为系统管理员，我希望维护角色菜单权限，区分系统管理员、业务管理人员、车间操作工的访问范围，以便实现业务数据权限隔离。
3. 作为系统管理员，我希望查看系统操作日志，以便追溯库存、工单等关键数据的操作人和操作时间。
4. 作为系统管理员，我希望维护物料、不良原因等基础字典数据，以便业务人员下拉选择使用。

### 2. 业务管理人员 用户故事
1. 作为业务管理人员，我希望维护宁波、合肥两地仓库档案，以便管理双基地仓库基础信息。
2. 作为业务管理人员，我希望物料入库时录入物料批次号，以便后续开展物料批次追溯。
3. 作为业务管理人员，我希望物料出库时系统按照FIFO先进先出自动推荐批次，以便优先消耗较早入库物料。
4. 作为业务管理人员，我希望输入原材料批次号，可以查询该批物料被哪些工单领用、产出哪些成品，以便质量问题溯源。
5. 作为业务管理人员，我希望输入成品批次号，可以反向查询生产所耗用的全部原材料批次，以便零部件质量排查。
6. 作为业务管理人员，我希望配置物料呆滞时间阈值，系统自动标记呆滞物料并展示预警，以便减少物料积压、降低资金占用。
7. 作为业务管理人员，我希望执行库存盘点，生成并导出库存台账Excel，以便仓库对账。
8. 作为业务管理人员，我希望查看库存上下限预警信息，以便及时发现缺料物料。
9. 作为业务管理人员，我希望创建生产工单，绑定零部件BOM、选择生产基地、分配给车间操作工，以便下达车间生产任务。
10. 作为业务管理人员，我希望查看全部工单进度、H5上报的生产照片、良品不良品数据，以便掌握整体生产情况。
11. 作为业务管理人员，我希望对操作工提交的完工工单做质检审核，填写质检结果，以便闭环生产工单。
12. 作为业务管理人员，我希望查看不良品原因分类统计图表，以便分析高频质量问题来源。
13. 作为业务管理人员，我希望工单质检合格后导出简易质检报告，以便交付主机厂客户。

### 3. 车间操作工（H5移动端） 用户故事
1. 作为车间操作工，我希望H5登录后查看分配给自己的工单列表，以便知晓待加工任务。
2. 作为车间操作工，我希望查看工单零部件信息与工序要求，以便按照标准开展加工。
3. 作为车间操作工，我希望填报工序加工进度，上传现场生产照片，以便上报加工情况。
4. 作为车间操作工，我希望填报本工序良品、不良品数量并选择不良原因，以便在生产过程记录次品信息。
5. 作为车间操作工，我希望全部工序完成后提交完工申请，等待业务管理人员质检审核。

## 三、核心业务用户行为路径
> 描述用户从进入系统，完成一项完整业务的操作步骤，用于梳理业务流程。

### 路径1：物料入库+批次录入（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台
2. 进入【库存单据管理】模块，新增入库单据
3. 选择所属生产基地（宁波 / 合肥），选择仓库
4. 选择物料，填写入库数量，录入该批物料的批次编号
5. 保存提交入库单，系统更新物料库存与批次库存数据
6. 入库完成；可进入批次追溯页面，查看该批次物料信息

### 路径2：物料出库（FIFO先进先出）（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，新增出库单据
2. 选择基地、仓库，选择要出库的物料
3. 系统自动优先展示最早入库未消耗完毕的物料批次（FIFO规则）
4. 确认出库批次、出库数量，提交出库单据
5. 系统扣减对应批次库存，生成出库记录

### 路径3：物料批次反向追溯查询（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入【批次追溯】功能页面
2. 输入原材料批次号，点击查询
3. 系统展示：该批次物料被哪些生产工单领用，这些工单产出哪些成品、成品批次编号
4. 支持导出追溯查询结果

### 路径4：成品批次溯源反查原材料（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入【批次追溯】
2. 输入成品批次编号
3. 系统展示生产该成品工单所消耗全部原材料以及对应原材料批次号

### 路径5：呆滞库存查看（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入【呆滞库存预警】页面
2. 系统根据预先配置的呆滞时间阈值自动筛选物料
3. 展示呆滞物料列表：物料名称、物料编码、最后出入库时间、呆滞天数
4. 业务管理人员查看预警，做物料处理决策

### 路径6：创建并分配生产工单（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入【生产工单管理】
2. 新增工单，选择生产基地、产品（拉索/踏板总成），绑定BOM信息，填写生产数量
3. 选择负责该工单的车间操作工，完成工单分配
4. 保存工单；工单状态变为待生产；操作工H5端可看到该工单

### 路径7：车间操作工H5报工+不良品录入（操作工‑H5移动端）
1. 车间操作工在手机浏览器打开H5页面，输入账号密码登录
2. 进入【我的工单】，查看分配给自己的生产工单列表
3. 点击工单进入工单详情，查看零部件、工序要求
4. 点击工序进度填报，填写本道工序加工进度
5. 上传现场生产照片
6. 填写本工序良品数量、不良品数量，选择对应的不良原因（原材料缺陷/设备问题/人工操作问题）
7. 保存本道工序报工记录
8. 全部工序加工完毕，点击【提交完工申请】
9. 工单状态更新为待质检；提交到Web后台等待业务管理人员审核

### 路径8：工单质检审核 + 导出质检报告（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入待质检工单列表
2. 选择操作工提交完工的工单，查看报工信息、现场照片、报工不良记录
3. 填写质检审核结果（合格 / 不合格），若不合格填写质检环节不良原因
4. 如果审核结果为合格，工单完成闭环
5. 点击导出质检报告，系统生成文档，可下载用于主机厂交付

### 路径9：不良品分类统计查看（业务管理人员‑Web后台）
1. 业务管理人员登录Web后台，进入质量统计页面
2. 选择统计时间范围、筛选生产基地（宁波/合肥）
3. 系统聚合H5报工不良、质检环节不良数据，按不良原因进行分类
4. 页面展示饼图/柱状图统计图表，支持导出统计数据Excel

### 路径10：系统管理员权限与操作日志（系统管理员‑Web后台）
1. 系统管理员登录Web后台
2. 用户管理：新增系统用户，绑定角色
3. 角色管理：为角色勾选菜单权限，控制各角色访问范围
4. 进入操作日志页面，查看用户对库存、工单、批次等关键数据的操作记录
