### 4.2 关键业务链路（务必在规划中闭环）
```
物料入库(录批次) → 库存/批次库存更新
      ↓
生产领料出库(FIFO扣批次, 关联工单) ──→ 工单(绑定BOM/工序, 分配操作工)
      ↓                                          ↓
成品入库(成品批次) ←── 质检审核(合格闭环) ←── H5工序报工(良品/不良/照片) → 完工申请
      ↓
批次双向追溯(原料批次↔成品批次) / 呆滞预警 / 不良统计 / 质检报告导出
```

### 4.3 现有文档已识别、且已拍板的缺口
| # | 缺口 | 结论 |
|---|------|------|
| G1 | `warehouse_material` 混合仓库与物料信息 | 保持单表（见 CONSENSUS Q1） |
| G2 | 无 BOM 表、无工序定义表 | 新增 3 表（见 CONSENSUS Q2） |
| G3 | `work_report_check` 多工序支撑方式 | 逐工序报工 + 整单质检（Q4） |
| G4 | 物料领用（出库关联工单）未闭环 | `stock_bill` 增 `work_order_id` |
| G5 | 工单状态机落点 | 后端 Service 硬编码 |
